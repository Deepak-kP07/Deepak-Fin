# Personal Fin — native Android app

React Native + Expo (SDK 58, Expo Router), plain JavaScript. It talks to the same Next.js API
(`/api/*` on personalfin.site) and the same Supabase project as the web app. There are no cookies
on native, so every request sends the Supabase access token as `Authorization: Bearer …`. The
server accepts that in `lib/supabase/server.js` (web project), and RLS still applies.

Package name: `com.personalfin.app`, the same as the old Capacitor wrapper, so it updates the same
Play listing. `versionCode` starts at 2 in `app.json`; bump it for every Play upload.

## Run it

```bash
cd mobile
cp .env.example .env          # fill in the Supabase URL + anon key (same as the web app's)
npm install
npm run android               # builds a dev build and installs it on a connected phone/emulator
```

`android/` is generated by `npx expo prebuild` (Continuous Native Generation) and is gitignored.
Change native settings in `app.json`, never in `android/`.

**Testing against a local API:** the deployed site only understands bearer tokens once the
`lib/supabase/server.js` change is deployed. Before that, run the web app locally (`npm run dev` in
the project root), put `EXPO_PUBLIC_API_URL=http://10.0.2.2:3000` (emulator) or your Mac's LAN IP
(phone) in `mobile/.env.local`, and restart `npm start -- --clear`.

## What's native so far

| Screen | Status |
|---|---|
| Sign in / sign up (email + password), resend confirmation | ✅ |
| Home — bank & cash balance, card dues, this month's income/spent/saved, recent | ✅ |
| Transactions — by month, grouped by day, pull to refresh | ✅ |
| Add / edit / delete expense & income (bank, cash, debit card, credit card), add & delete transfers | ✅ |
| Balance and credit-limit checks (same rules as the web form) | ✅ |
| Accounts — balances, debit cards, credit card usage | ✅ |
| More — privacy policy, sign out, delete account | ✅ |
| Other modules (cards, loans, lend/borrow, investments, budgets, …) | Opens the web app for now |

Hidden transactions never appear in lists, same as the web app. Scheduled, repayment, hidden and
attachment flows stay on the web for now.

## Release build (Play Store)

```bash
npx eas-cli@latest login
npx eas-cli@latest build:configure      # once — creates eas.json
npx eas-cli@latest build -p android --profile production   # produces the .aab
```

Use the same upload key as the closed-test build. If you build locally instead, keep the keystore
out of git (`*.jks` is already ignored).

## Layout

```
src/app/            routes (Expo Router)
  _layout.js        providers + signed-in / signed-out guard
  sign-in.js
  (tabs)/           Home, Transactions, Accounts, More
  transaction.js    add / edit modal
src/state/          AuthProvider (Supabase session), DataProvider (/finance/summary)
src/lib/            api client, secure session storage, formatting, transaction helpers, theme
src/components/     shared UI
```
